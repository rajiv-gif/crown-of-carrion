# Visual Direction

The Godot version should be judged screenshot-first.

Immediate target:
- One Ash Road battle should look like a dark fantasy tactical RPG screenshot.
- The battlefield is a painted location, not a visible UI board.
- Units are small readable pieces until an attack starts.
- Attacks use camera/cut-in/impact language, not just token movement.
- UI is quiet and secondary to the map.

Do not port every web mechanic before the scene looks good.
